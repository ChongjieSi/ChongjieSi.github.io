# 海岸城：森林与活动角色碰撞修整

2026-11-24，本地版本 36。

## 实现

- 路人和六类动物的当前位置由模拟维护，渲染读取并插值这些位置。移除路人只在渲染中偏移、动物沿正弦轨迹直接跳到终点的做法。
- 活动角色按半径和高度参与玩家、车辆、静态场景及彼此之间的碰撞。角色移动按不超过 0.12 米的子步检查，车辆沿用自身更细的扫掠步进；不同楼层和飞行高度分别处理。车辆遇到角色会制动停止。
- 路人避让车辆，动物会对靠近的玩家和车辆作出回避。路径决策约每 0.12 秒更新，实际移动仍随物理步进运行；坡度结果缓存限制为 8,000 项。
- 静态场景装配后重新检查角色初始位置，避开后来生成的树、石头、设施和其他角色。
- 隧道仅在实际覆土段裁切森林地形，保留露天接近段的地表；出口门框对齐最后一段的末端。
- 溪边石头按岸边地形落位，碰撞范围从实际旋转后几何包围盒计算。
- 延长山脊停车区至观景亭的步道，为两个亭子的地板提供与可见板面一致的行走高度。
- 给入口和停车路牌补立柱并保持通路净空，观景亭旁增加可随昼夜切换的灯具。
