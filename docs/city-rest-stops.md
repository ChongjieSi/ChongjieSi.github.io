# 海岸城：林间停留点与街区细节

2026-11-24，本地版本 37。

## 这一轮的体验

- **溪谷驿站**：木平台、遮雨导览板、按真实游戏路网绘制的步道图、长椅、花箱、分类垃圾桶、饮水龙头和暖光灯。补充饮水恢复体力，并短暂显示龙头水流。
- **溪畔观察台**：沿溪步道接入有栏杆的木平台，留有明确入口，配置长椅、生态说明和三脚观景镜。
- **山脊观景镜**：利用现有观景亭，可实际放大城市和海湾。相机置于镜头前端，拖动环顾，滚轮或加减按钮调整视野，E 或移动退出。退出后恢复原朝向，观景期间交通和动物继续运动。
- **林间手记**：首次互动记录每一处停留点，单处奖励 80 分，三处集齐再奖励 240 分；记录保留至本局结束。任务的“探索”页可以查看收录进度、设置导航，地图的“自然”分类支持选择和传送。
- **街区设施**：六处街角增加分类垃圾桶，公共书架和街头舞台旁增加自行车、停车架及各自的公告板。设施使用真实几何和碰撞体。

## 地形与性能

新平台提供与可见木板一致的行走面，调整周围地形，避免草坡顶穿平台。驿站入口从公路侧面接入，沿接路位置的实际坡度过渡。土路几何按公路和平台的实际边界裁切，保留 UV 插值，避免泥土纹理盖在沥青、木板上。裁切包含高度范围，分层道路不会一律挖掉。

重复构件使用实例化绘制，新增两处局部灯仅在夜间且玩家靠近时开启。不增加外部贴图库或网络依赖。Worker、游戏入口和主页入口的缓存版本同步更新到 37。
