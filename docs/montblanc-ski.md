# 勃朗峰 · 雪境

可在浏览器实际操控的 3D 滑雪游戏，已接入主页 Games，游戏 ID 为 `ski3d`。

## 运行

现有项目：`hugo server --bind 127.0.0.1 --port 1313`，打开 <http://localhost:1313/games/?game=ski3d>。

无需 Hugo 的静态运行：在仓库执行 `python3 -m http.server 8080 --directory static`，打开 <http://localhost:8080/games/?game=ski3d>。需要通过 HTTP 提供文件，不能直接双击 HTML，因为游戏要加载 ES module 和二进制高程数据。WebGL 和现代浏览器是必需条件。运行时资源均在项目内，不依赖在线地图 API。

## 核心实现

- **真实地形**：AWS Terrain Tiles / Mapzen Terrarium 的实际高程，不是随机雪山。经纬度范围 6.79–6.97° E、45.80–45.94° N；769×769 样本，约 14×15.6 km。轴向采样间距约 18–20 m，0.25 m 是高度编码精度，并非原始测量精度。勃朗峰、塔库尔与南针峰位置来自地理坐标。
- **真实雪面变化**：独立 0.2 m 雪层网格记录变形。两条板迹会压低雪面；近处细分网格直接读取同一份高度，重建顶点与法线，物理也读取这份高度。远处另有贴地轨迹带提高可见性，不代替近处的几何凹槽。
- **滑行**：120 Hz 固定步进；重力来自实际坡度；有滑板方向、侧滑阻尼、刻滑转向、撑杖、刹车、腾空、落地冲击、跟随视角和第一人称视角。路线标记由 DEM 的下坡方向生成，属于游戏导航，不是实地雪道或安全线路。
- **雪崩**：72 个有体积、速度的流动雪包。释放区的雪层高度减少，雪包受局部重力和摩擦作用，在低速区沉积，沉积增加同一份雪面高度。活动雪包会推移滑手，暴露量过高会卷入；R 可恢复。没有预先录制的雪崩轨迹。
- **持久化**：IndexedDB 每约 20 秒自动保存，也能手动保存，记录雪层、轨迹、活动雪包与沉积量。恢复检查 DEM 版本指纹。保存当前雪面，不保存成绩、滑手位置或任务进度；排行榜仍需要玩家结束后主动提交。
- **玩法与反馈**：三个真实地理起点、顺坡标记、落差与距离计分、地形图、速度 FOV、粉雪反馈、可开关的速度驱动风雪声、触屏按钮、安全点恢复。

## 操作

A / D 或左右键转向；W / 上键撑杖；S / 下键 / 空格刹车；J 起跳；C 切换视角；按住 V 回望山峰；M 地形图；R 返回最近安全点。手动雪层试验通过按钮在当前位置上坡释放雪体；陡坡持续扰动也可能自动触发。恢复安全点和切换起点不会清空已有雪迹。

## 数据与可复现性

`static/games/ski-data/provenance.json` 包含每张来源瓦片的 URL 和 SHA-256、区域范围、编码、下载日期及最终 DEM 指纹。`scripts/build-montblanc.py` 可重建数据，依赖 Python、Pillow、NumPy；它读取实际 Terrarium PNG 的高程通道，再做地理重采样。

数据：Terrain Tiles via AWS Open Data / Mapzen。Europe terrain data produced using Copernicus data and information funded by the European Union — EU-DEM layers。Global SRTM / GMTED2010 courtesy of USGS。

## 视觉重制（2026-11-24）

- 远景网格直接使用全部 769×769 DEM 样本，近景边缘对齐远景实际三角形高度、法线与颜色，减轻接缝。远景轨迹带也按对应的可见三角形表面贴合。
- 雪面与花岗岩使用项目内生成材质，按世界坐标与坡度混合，加入风蚀微法线与岩层细节。材质及完整生成提示词在 `static/games/ski-data/materials/README.md`。它们属于美术表现，不是地表测绘数据。
- 地形自身遮挡生成山脊阴影，滑手附近有实时柔化投影；高空渐变、远景雾和低海拔山谷云增强空间感。云雾为视觉效果，未参与天气物理。
- 滑手改用曲面衣服、关节四肢、屈膝随动、背包、头盔、雪镜、雪靴、固定器及上翘双板；喷雪用柔边粒子。仍为代码制作模型，不是扫描角色或动作捕捉。
- 重排开场与 HUD，修复画布容器继承零行高导致的文字重叠。工具收起到菜单，桌面显示键位提示、触屏显示操作按钮。峰名会检查地形遮挡，避免穿过山体显示。
- 输出像素预算上限约 320 万，按窗口及设备像素比适配；这不是保证固定帧率的承诺。

## 明确的边界

这是历史 DEM 和可变形游戏雪层；未使用实时雪深、LiDAR、冰川裂隙测绘或当前峰顶测量，数十米级高程无法还原单块岩石、真实冰裂缝或完整雪道。雪崩是有体积收支的深度简化雪包模型，不是连续介质有限体积求解器，也没有真实雪晶、温度、风荷载和应力断裂力学。雪体外观采用体积驱动的球团网格与半透明雪雾，不应称为电影级体积渲染。真实物理只在上述边界内成立。

近景变形覆盖滑手附近 40×40 m，离开后数据仍保留，返回时重建。远景山形使用静态 DEM；远处不会实时重建厘米级雪痕及沉积。移动端降低设备像素比上限，但尚不能承诺所有手机 60 FPS。没有多人同场、缆车系统、完整动画捕捉或商业级角色美术。

## 验证

`node --test tests/ski-world.test.cjs tests/ski-view.test.mjs` 使用实际打包的 DEM，检查地理坐标、三处起点、刹车、左右转向、起跳、双板持久凹槽、雪崩运动与体积守恒、雪体对滑手的影响；渲染场景检查近远地形边缘高度、雪面顶点变形、关节模型与多种视角矩阵。CPU 场景检查不代替 GPU 画面验收。Safari 实际装载 WebGL 地形、进入游戏并进行下坡加速，观察到速度和下降高度实时变化。尚未完成全部路线的人工通关或手机真机性能验收。
